Búsqueda de Dos Máximos

Aritmética de apuntadores en matrices bidimensionales

Conceptos clave
🧭
Apuntador base
int *ptr = &matriz[0][0]

Una matriz 2D en C es contigua en memoria. Con un solo apuntador al primer elemento podemos recorrer toda la matriz usando *(ptr + i).
🥇
max1 y max2
No guardamos valores, guardamos direcciones. max1 apunta al elemento más grande encontrado. max2 apunta al segundo más grande.
📏
Resta de apuntadores
max1 - max2 devuelve la distancia en elementos, no en bytes. C divide automáticamente entre sizeof(int).

El código que había que completar
PJ2.c — lógica de búsqueda 
for (int i = 2; i < total; i++) {
    int *actual = (ptr + i);

    // Caso A: actual supera al campeón actual
    if (*actual > *max1) {
        max2 = max1;    // el campeón baja al 2do lugar
        max1 = actual;  // el nuevo campeón toma el 1er lugar
    }
    // Caso B: actual supera al 2do pero no al 1ro
    else if (*actual > *max2) {
        max2 = actual;  // desplaza al 2do lugar
    }
}
¿Por qué la resta no devuelve bytes?
Supón que max1 está en 0x100 y max2 en 0x108. Así se ve la memoria:
0x100
42
[0] max1

17

0x10C
5
[3]
0x110

Cada int ocupa 4 bytes. Entre 0x100 y 0x108 hay 8 bytes físicos, pero 2 enteros.
Diferencia en bytes: 0x108 − 0x100 = 8 bytes
C divide automáticamente: 8 ÷ sizeof(int) = 8 ÷ 4 = 2
Resultado de max2−max1: 2 (elementos, no bytes)
¿Por qué C hace esto? Porque cuando trabajas con arreglos, lo que te importa saber es cuántos elementos hay entre dos posiciones, no cuántos bytes. Si quieres los bytes, multiplicas manualmente: distancia * sizeof(int) → 2 × 4 = 8 bytes.
